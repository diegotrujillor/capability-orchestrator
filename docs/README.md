# Docs

Documentos para compartir el modo de trabajo del orquestador con un equipo.

## Quién lo usa / ejecuta

- Personas del equipo que quieren entender cómo usar `capability-router`.
- El agente cuando necesita explicar o presentar el flujo de trabajo.

## Orden lógico

```text
1. Leer WORKING-MODE.md para entender el proceso completo.
2. Usar FIRST-RUN.md para ejecutar el primer caso real.
3. Consultar README.md para la visión general del repo.
```

## Archivos

- [WORKING-MODE.md](./WORKING-MODE.md): resumen presentable del lifecycle y modo de trabajo.
