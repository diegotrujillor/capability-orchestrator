# Ejemplos

Esta carpeta contiene casos semilla sintéticos y ejemplos de uso.

Todos los ejemplos son ficticios. No contienen datos de ningún cliente, empleador ni sistema real. Su valor está en el **patrón**, no en el contenido.

## Quién lo usa / ejecuta

Los consultan el agente o la persona al comparar una solicitud nueva con casos anteriores.

## Orden lógico

```text
1. Leer nueva solicitud
2. Buscar caso semilla parecido
3. Reusar patrón de análisis
4. Adaptar al nuevo contexto
```

## Para qué sirve

Sirve para mostrar patrones recurrentes que el orquestador debe aprender a reconocer.

## Casos incluidos

- [`mixed-qa-report/`](./mixed-qa-report/): caso mezclado que obliga a separar frentes funcionales.
- [`full-cycle-feature/`](./full-cycle-feature/): ciclo completo con arquitectura, implementación, SOP (Standard Operating Procedure / procedimiento operativo estándar) y promoción entre ambientes.

## Cuándo se usa

Se usa cuando necesitas:

- entender qué tipo de caso entra en esta iniciativa;
- comparar una solicitud nueva con casos anteriores;
- decidir qué capacidad aplicar;
- explicar el tipo de salida esperada.
